# Keyword and intent map

One primary query per page, for all 110 tools. **None of the volume, difficulty or SERP notes is measured**: they are estimates from general knowledge, written without a keyword-research tool. Use them to order work, then replace them with real queries from Search Console and Bing Webmaster Tools.

> Generated by `npm run docs:seo` from `packages/tools/src/seo/keyword-map.ts`. Do not edit this file by hand; edit the data file and run the script.

## What the results usually look like

| Kind of tool | What the top results usually offer (unverified) |
| --- | --- |
| pdf | Large PDF-tool sites with strong authority: a drop zone, a server-side upload, a daily limit or a paid plan, watermarks or sign-up on some jobs, and ads. Many say files are deleted after an hour. |
| image | Large image-tool sites and a few single-purpose tools: upload to a server, file-count or size limits, ads, and a paid tier for batches. |
| dev | Single-purpose developer tools and long-standing utility sites: fast and plain, often with ads, many send input to a server, and few explain limits or edge cases. |
| data | Converter sites with a paste box and a copy button; some upload the data, most have little explanation beyond the tool. |
| text | Small utility sites and word-processor style tools: instant results, heavy ads, thin explanation. |
| calc | Finance, health and unit-conversion sites with strong authority, long explanatory articles around the calculator, and ads. |
| design | Design-tool sites and generators: polished UI, often a sign-up or a paid plan for export or no expiry (QR codes), and tracking. |
| gen | Generator sites with ads; QR and barcode generators often push a paid plan or a tracking redirect. |
| enc | Encoder and hash utility sites: a paste box with minimal explanation, some of which send the input to a server. |

Our angle on every page is the same, and it is true: your files never leave your device, there is no sign-up, no watermark, and nothing to pay for.
